# Ternary Logic GF(3)
In boolean logic, everything can be represented mathematically as polynomials over the finite field GF(2) (where $1 + 1 = 0, mapping perfectly to XOR). Ternary logic (using states -1, 0, 1) maps directly to GF(3).
