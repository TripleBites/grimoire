# Rule VM: registers and ops

Generated by `rulelab docs` from `crates/vm/src/ops.rs`. Do not edit by hand.

A learn program is 0 to 8 instructions of 16 bits, `op[15:12] dst[11:8] a[7:4] b[3:0]`, run once per synapse per step. `dst` must be r12 to r15; any other value is an error. Unary ops are written `op dst a`; the rest `op dst a b`.

## Registers

| Reg | Name | Meaning | Initial value |
| --- | --- | --- | --- |
| r0 | `pre` | presynaptic activation x_i | input |
| r1 | `post` | postsynaptic output y_j | input |
| r2 | `agg` | postsynaptic pre-activation a_j | input |
| r3 | `w` | current weight (dequantized) | input |
| r4 | `tr` | current per-synapse trace | input |
| r5 | `sig` | signal at unit j | input |
| r6 | `nbr` | mean output of j's layer | input |
| r7 | `noise` | uniform in (−1, 1), fresh per synapse per step | input |
| r8 | `one` | 1.0 | constant |
| r9 | `neg` | −1.0 | constant |
| r10 | `k1` | spec constant | constant |
| r11 | `k2` | spec constant | constant |
| r12 | `dw` | output: weight delta, applied as w ← Q(w + η·dw) | 0 |
| r13 | `ntr` | output: new trace | tr |
| r14 | `t0` | scratch | 0 |
| r15 | `t1` | scratch | 0 |

An empty program is the identity: `dw` = 0 and the trace is kept.

## Ops

| Code | Op | Form | Semantics |
| --- | --- | --- | --- |
| 0 | `mov` | `op d a` | d = a |
| 1 | `add` | `op d a b` | d = a + b |
| 2 | `sub` | `op d a b` | d = a − b |
| 3 | `mul` | `op d a b` | d = a × b |
| 4 | `neg` | `op d a` | d = −a |
| 5 | `sign` | `op d a` | d = sign(a), sign(0) = 0 |
| 6 | `abs` | `op d a` | d = abs(a) |
| 7 | `min` | `op d a b` | d = min(a, b) |
| 8 | `max` | `op d a b` | d = max(a, b) |
| 9 | `gt` | `op d a b` | d = 1 if a > b else 0 |
| a | `sel` | `op d a b` | d = a if d ≠ 0 else b (d is the condition) |
| b | `ema` | `op d a b` | d = (1 − b) × d + b × a |
| c | `thr` | `op d a b` | d = a if abs(a) > abs(b) else 0 |
| d | `clip` | `op d a b` | d = a clamped to ±abs(b) |
| e | `relu` | `op d a` | d = max(a, 0) |
| f | `tanh` | `op d a` | d = tanh(a) |

## Rule numbers

A program is canonicalized before numbering: dead instructions are dropped, unused `b` fields are zeroed, and the operands of commutative ops (`add`, `mul`, `min`, `max`) are sorted. The number is `R<length>-<hex words>` joined by `.`, for example `R1-3c01` (`mul dw pre post`, Hebbian). The empty rule is `R0`.
