

# Project Structer:
```
grimoire/
├── .git/
├── .gitignore              # Ignore data/, venv/, .ipynb_checkpoints/, and compiled C objects
├── .gitattributes          # Configure Git LFS tracking for datasets/model weights
├── pyproject.toml          # Central configuration for uv, dependencies, and project metadata
├── uv.lock                 # Deterministic dependency locking generated by uv
├── README.md
│
├── src/                    # The core Python package (src layout prevents import collisions)
│   └── grimoire/
│       └── __init__.py
│
├── ext/                    # Dedicated folder for C source code
│   ├── include/            # C headers
│   └── kernels.c           # Low-level implementations (e.g., fast math, SIMD operations)
│
├── notebooks/              # Jupyter Notebooks / Colab targets
│   └── 001_perceptron.ipynb   
│
├── tests/                  # PySys testing infrastructure
│   ├── pysysproject.xml    # Global PySys configuration
│   └── test_core_math/     # Individual PySys test cases
│       ├── pysystest.xml
│       └── run.py
│
└── data/                   # Local datasets (NEVER commit this directly unless using LFS)
    ├── raw/
    └── processed/
```
